## 📖 Overview
**Recase** is a 3D detective simulation game developed as a Computer Engineering capstone project. Powered by Generative AI, players step into a fully procedural, breathing world to gather evidence, interrogate autonomous NPCs using natural language, and crack the case.

Because the core game logic is entirely driven by Large Language Models (LLMs), **Recase** offers infinite replayability where no two investigations are ever the same.

## ✨ Key Features
* **100% AI-Generated Mysteries:** Every aspect of the case is procedurally generated at the start of a new game. The identity of the killer, the crime scene, the evidence, NPC names, and even what the characters know about each other are completely fabricated by the AI.
* **Powered by Groq (BYOK):** The game utilizes the lightning-fast **Groq API**. Players bring their own Groq API keys, select their preferred high-speed LLM, and start investigating with zero dialogue latency.
* **Dynamic World & NPC Routines:** The game features an active day/night cycle. NPCs don't just stand around waiting for you; they have daily schedules, routines, and activities that they follow in real-time.
* **Free-Text Interrogations:** Engage in natural, dynamic conversations. You are not limited to pre-written dialogue trees—type whatever you want to ask, pressure suspects, or confront them with the evidence you found.
* **Smart Journal:** Keep track of your gathered evidence, clues, and suspect statements seamlessly with the automated in-game Smart Journal.

**[Download Recase (Google Drive)](https://drive.google.com/drive/folders/12m7KxEto6ey5ckgtkjpMksn1E89PUBTo?usp=sharing)**

### How to Start:
1. Download and extract the game files.
2. Get your free API Key from [GroqCloud](https://console.groq.com/).
3. Launch the game executable.
4. In the main menu, enter your Groq API key and select your preferred model.
5. Start the game, observe the routines, interrogate the suspects, and catch the killer!
